# Trainer Application

This library contains the application use cases for the Trainer domain.

## What's Inside

- **Use Cases**: Orchestrate domain logic
  - `ListTrainersUseCase`: Get all trainers
  - `GetTrainerByIdUseCase`: Get a specific trainer
  - `AddFavoritePokemonUseCase`: Add a Pokemon to favorites
  - `EarnBadgeUseCase`: Award a badge to a trainer

## Dependencies

- Depends on: `@pokedex-app/trainer-domain`
