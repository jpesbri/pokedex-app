# Trainer Domain

This library contains the core business logic for the Trainer domain.

## What's Inside

- **Entities**: Trainer entity with business logic
- **Value Objects**: TrainerBadge enum
- **Repository Interfaces**: Contracts for data access

## Business Rules

- Trainers can earn badges (max 8 for champion status)
- Trainers can have favorite Pokemon (max 6)
- Badge collection and favorite management logic
