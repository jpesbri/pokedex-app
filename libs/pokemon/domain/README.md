# Pokemon Domain

This library contains the core business logic for the Pokemon domain.

## What's Inside

- **Entities**: Pokemon entity with business logic
- **Value Objects**: PokemonType enum
- **Repository Interfaces**: Contracts for data access

## Key Principles

- Pure business logic with no framework dependencies
- No infrastructure concerns (database, HTTP, etc.)
- Highly testable in isolation
- Contains the "truth" about Pokemon business rules
